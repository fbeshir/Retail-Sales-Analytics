# Retail Sales Analytics | Python Portfolio Project

## Project Overview
Analyzed 500 simulated retail orders using Python to identify revenue trends, top-performing products, and regional sales performance.

## Tools Used
- Python
- pandas
- NumPy
- Matplotlib
- Google Colab
- GitHub

## Key Findings
- **Total Revenue:** $620,300
- **Total Orders:** 500
- **Average Order Value:** $1,240.60
- **Top Product:** Monitor ($144,800)
- **Top Region:** South ($172,450)

## Data Quality
- 500 rows analyzed
- No missing values
- No duplicate order IDs

## Business Recommendations
1. Investigate why monitors generate the highest revenue.
2. Compare regional performance to identify potential improvements.
3. Analyze monthly sales trends to understand revenue fluctuations.

## Project Files
- `Retail_Sales_Analysis_.ipynb` — Python code and visualizations
- `retail_sales_data.csv` — Synthetic retail sales dataset

## About the Dataset
This project uses synthetic data generated with Python for educational and portfolio purposes. Results do not represent actual company performance.
